# Personal child profiles

V20 adds a child-profile flow based on the supplied UI concept image:

Welcome -> name -> avatar -> favorite color -> ready -> Home.

Up to 3 child profiles are stored locally with AsyncStorage. Each profile has its own name, avatar, favorite color, stars and games played. The selected child persists between launches. Tapping the Home avatar opens the personal profile dashboard; the dashboard can open the child selector.

The supplied concept collage was cropped into individual reference assets under `assets/*-reference.png`. No emoji is used as the visual avatar.
