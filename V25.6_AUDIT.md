# V25.6 Core Fixes

## Fixed
- Shared round-game scoring now calculates the score from the selected answer exactly once on `next()`, eliminating stale-state/double-counting on the final round.
- Colors scoring now follows the same single-commit rule.
- Draw completion no longer triggers when repainting an already-painted area.
- Animals level 12 now marks the overall Animals game completed after the final level is completed.
- Android status bar is hidden so the reference artwork can occupy the full available app viewport instead of leaving a top system-bar strip.
- Home continues to use uniform cover scaling and the same transform for its hit areas and dynamic overlays.

## Verified statically
- No missing local `require()` targets found.
- No helper files under `app/` requiring Expo Router default exports.

## Not yet verified
- A real Expo install/build could not be completed in this environment because `npm install` timed out.
- Mixed-aspect-ratio reference artwork (especially the landscape Profile artwork) still requires dedicated portrait artwork for pixel-faithful full-screen rendering without cropping.
